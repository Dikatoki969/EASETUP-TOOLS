# 📥 INSTALLATION

Run this command as **root**:

```bash
bash <(curl -s https://raw.githubusercontent.com/Dikatoki969/EASETUP-TOOLS/main/install.sh)
```

Alternative:

```bash
curl -s https://raw.githubusercontent.com/Dikatoki969/EASETUP-TOOLS/main/install.sh | bash
```
